端侧模型部署

概述

这篇博客介绍嵌入式 AI 部署相关的知识。包含环境搭建 -> 模型训练 -> 模型转换 -> 模型部署。

0 LubanCat-4 RK3588S2 && 基本信息

电源接口: Type-C5V@4A 直流输入
主芯片: RK3588S(四核 A76 + 四核 A55，采用了大小核架构、Mali-G610、三核 NPU 6T 算力)
内存: LPDDR4X-4GB
存储: eMMC-32GB
基本配置信息：https://doc.embedfire.com/linux/rk3588/quick_start/zh/latest/quick_start/lubancat/lubancat4.html

官方仓库: rknn-toolkit2(RKNN-Toolkit2 模型转换工具，将主流框架模型转换成可以在 NPU 上跑的 RKNN 模型，RKNN Runtime 板端运行库，运行在开发板上的一个 C/C++ 推理库), rknn_model_zoo(包含目前主流算法的部署例程，例程包含导出的 RKNN 模型，使用 Python api, C api 推理 RKNN 模型的流程), rknn-lmm, librga(RGA 是一个独立的 2D 硬件加速器，可用于加速点/线绘制，执行图像缩放、旋转等常见的 2D 图形操作)。

1 rknn-toolkit2 开发环境搭建(PC端 x86)

VMware + ubuntu20(20.04.4) + miniconda(安装 + 换源) + 安装 toolkit 需要的软件包(在该仓库的 rknn-toolkit2/packages/x86_64 子目录下；whl 文件 - 核心安装包 + requirements.txt - 第三方 Python 依赖包)。

2 设备端 NPU 环境准备

驱动版本确认： RKNPU driver xxx(v0.9.8)

NPU 连板环境确认：RKNN-ToolKit2 的连板调试功能依赖板端的 RKNN Server 程序，该程序是一个运行在开发板上的后台代理服务，用于接收 PC 通过 USB 传输过来的命令和数据，然后调用相应的运行时接口，并返回相应结果给 PC。RKNPU2 Runtime 库 - librknnrt.so(用于 RK3588 板端的 Runtime 库)。要保证 RKNN Server、Runtime 库版本、RKNN-Toolkit2 版本一致。

4 RKNN 模型转换

需要将不同框架下的神经网络模型转换成 RKNN 模型。(.pt 模型会先转换成 onnx 模型最后转换成 .rknn 模型)
模型转换流程：创建 RKNN 对象 -> 配置 RKNN 模型 -> 加载对应的模型 -> 构建 RKNN 模型 -> 导出 RKNN 模型 -> 释放 RKNN 对象

5 模型转换工具 rknn_convert

常用模型转换工具，只需要编辑对应的 yml 配置文件，就可以通过指令转换模型。

6 Netron 的基本使用

微软推出的可视化模型结构工具，支持查看多种深度学习框架导出的模型(包括 RKNN 模型)。

模拟器测试->连板推理测试->真实部署

8 模型量化精度分析 性能、内存评估

什么是量化？ 量化指把模型中的浮点参数和操作转换为定点表示。FP32 -> INT8 大幅缩减模型体积， NPU 更适合处理 INT8 运算，提升推理速度，降低功耗。PTQ(训练后量化，直接把训练好的模型进行量化); QAT(在训练过程中就去模拟量化，模型自适应精度损失); 混合精度量化。量化会带来精度损失。
Rknn-toolkit2 提供两种量化方式(Layer, Channel)和三种量化算法(Normal, MMSE-精度最高，暴力迭代, KL-Divergence)。
常规量化(模型中的权重和激活值只采用一种量化精度类型。可以调用 rknn.accuracy_analysis() 逐层对比浮点模型和量化模型的输出结果，输出余弦距离和欧式距离，用于分析量化模型精度下降的原因)和混合量化(权重和激活值可以采用不止一种量化精度类型，例如某些层采用 int 16，某些层采用 int 8)。

9 模型剪枝 && 加密

可以分为有损剪枝和无损剪枝，Rknn-toolkit2 的模型剪枝为无损剪枝，无损剪枝是根据模型的权重的稀疏化程度来去除一些对模型结果不造成影响的权重和 Feature 通道。
结构化剪枝 + 微调，需要在 PyTorch 训练阶段主动介入，移除整个卷积通道或网络层(结构化剪枝)。
生成完模型后再重新对其做进一步处理，处理过的模型不能再通过 Netron 查看网络结构了。

10 多 batch && 多输入模型 && 动态 shape 输入

开启多 batch 推理时，内部会调用 rknn_dup_context() 将 context 进行拷贝。为了让模型跑的更快。

多输入神经网络是一种能够同时处理多个不同来源、不同模态或不同特征的数据输入的深度学习模型架构。(简而言之就是多模态 / 多个不同的特征向量)
动态 shape 输入是指模型输入数据的形状在运行时可以改变，无需为每个尺寸重新转换或加载一个模型文件。在确认模型支持动态 shape 后，设置需要使用的输入形状。设置 rknn.config() 中的 dynamic_input = dynamic_input 即可支持推理时输入不同尺寸的数据(在列表中的)。

11 自动生成部署 C 代码 && RKNN-ToolKitLite2(直接用于部署，基于 python api 适合快速验证)

RKNN-ToolKit2 2.0.0版本新增 Codegen 接口，用于生成模型部署代码。基于 CAPI 零拷贝接口进行的二次封装。

RKNN-ToolKitLite2 为用户提供板端模型推理的 python 接口，方便用户使用 python 进行 AI 应用开发。

13 大模型部署(qwen3-vl-2b-instruct_w8a8_rk3588.rkllm)

这里以部署 qwen3-2b 模型为例展示端侧大模型部署的过程。
RKLLM-Toolkit 支持将 Hugging Face 和 GGuf 格式的 LLM 转换成 RKLLM 模型，转换后的模型能够在 Rockchip NPU 平台上加载使用，还支持量化功能，其中 w8a8 表示分组量化。

a）环境配置

安装 RKLLM-Toolkit 的软件环境。


你可以选择开源的 LLM 或者自行训练得到的 LLM，要求是 GGUF 模型，通过 RKLLM-Toolkit 进行模型的加载、量化配置并导出成 rkllm 格式。当然你也可以选择使用 RK 官方转换好的模型：https://meta.box.lenovo.com/v/link/view/ad7482f6712844b48902f07287ed3359 (rkllm)。这里选择的是后者，前者不再赘述，因为虚拟机没有显卡可能会出现转换不成功的情况。
