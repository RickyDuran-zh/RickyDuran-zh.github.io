Hello World.

前言

就像每个刚开始学习coding的人一样，第一个手写的程序恐怕就是helloword.c了。DevC++的大蓝图标，白底的编辑器，纯黑的命令行成了我对coding的initial impression。此篇博客的目的便是如此。Motivation有很多，但是我想主要还是以下的几个。

分享欲

许久没有写文字整理自己的思路了(上次写这种大段碎碎念恐怕得追溯到大一大二了，想来真是一段十分自由的时光)，我怕是连语言都组织不利索了。还记得很久之前在远子的一本小诗集上看到的一句话：“母语是需要呵护的”，哈哈哈想来是被我忽视太久了，但有时又不免觉得有点太矫揉造作了。我向来不是对自己的存在非常笃定的人，但也不乏有分享欲爆棚的时刻，写在这里也不必担心被别人看到吧。对了博客整体的工作流是hexo + github pages静态托管，感觉用起来还是相当顺手的，这里还是受到了F君的启发嘿嘿(自己真的是一个很容易被inspired的人)。

和Y在一起的生活

过去的两个月可能是迄今为止最开森的两个月了，一小部分的原因是终于写完了第一篇会议，虽然到现在这个时间点为止还没有投出去。大部分我想都应该归功于Y吧，3.1在一起到现在满打满算两个月的时间吧。进展之快，过程之离谱，回想起来只觉得相当魔幻，但是是往好的方向发展的哈哈。只记得去年年末的时候，自己相当抑郁，相当depressed，甚至跨年都是和北航的哥们连麦，在宿舍刷leetcode度过的(至少刷完了hot100)，我这人喜欢和自己较劲，有点stubborn，但是自己想通了，又转变的很快。总之这两个月超级幸福，和Y在一起相当甜蜜，感恩现在吧嘿嘿。

技术成长

这可能是最主要的原因了吧，自己大概率是不考虑读博的。其实也反复横跳了很久，说的好听点是在两个选择里犹豫纠结(至少还有的选不是哈哈)，但现实恐怕是没有锚定好自己的未来，依然觉得迷茫吧。要是想进工业界读博就是在浪费生命这种”暴论”也不无道理吧我想，而且我实在不喜欢抱团取暖，陪Boss过家家的戏码。于是乎在这里记录学习Linux应用和驱动，OS，有趣的技术栈和项目，当然还有和Y在一起的日常啦，嘿嘿，时间过得太快了，要是不留下点痕迹，日后恐怕是要后悔的。

结尾

有点懒，有点爱折腾，有点三分钟热度，有点什么都想试一下，这可能就是我嘿嘿。最后如果你不幸看了我的帖子，甚至不幸地对你产生了一定帮助或影响的话，这可能是我存在的最大意义了。
