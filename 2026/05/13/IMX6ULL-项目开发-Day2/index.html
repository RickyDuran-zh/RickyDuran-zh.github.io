IMX6ULL-项目开发-Day2

一、GPIO和Input子系统篇 Led、Buzzer、Key

1.GPIO子系统 需要注册字符设备(函数接口)

1.设备树修改(用户led 彩色led buzzer)

2.驱动流程

GPIO输出 用户接口：/dev/edge_led && /dev/edge_buzzer

2.Input子系统 不需要注册字符设备，所以不需要函数接口

驱动不需要自己定义/dev/key这种私有接口，而是把输入事件上报给 input core，由 input core 统一生成/dev/input/eventX。

1.设备树修改(key)

input_dev 代表一个具体的输入设备

2.驱动流程

GPIO 输入 + 中断 IRQ + input 子系统事件模型 用户接口：/dev/input/eventX

a) 在 probe 中获取 gpio, gpiod_to_irq()把 gpio 转为IRQ
b) 分配 input_dev, 设置 input 设备支持的事件类型和键值
c) 注册 input 设备， 申请 gpio 中断
d) 中断触发后读取 gpio 电平值, input_report_key()上报事件, input_sync()同步事件

input_dev核心结构体

probe函数

3.实验结果

暴露给用户层面的接口：
/dev/edge_leds
/dev/edge_buzzer
