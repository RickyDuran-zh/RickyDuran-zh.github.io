IMX6ULL-项目开发-Day6

概述

EdgeGuard-6ULL: 支持网络与远程访问、数据持久化、消息上报。

P1 Http

edgeguard_httpd.c 实现了 PC 浏览器(网线直连)直接访问板子 IP 读取实时状态。本地端口访问，http://192.168.10.2:8080。
1 为网卡 eth2 手动配置静态 ip 地址

2 sudo systemctl restart networking 读取配置文件 应用静态 ip
3 ip addr show eth2 查看 ip 地址

P2 SQLite(嵌入式数据库)

轻量级的、零配置的、单文件的嵌入式数据库引擎。不是一个独立的服务器进程，可以直接嵌入到应用程序中的代码库(sqlite3.c)，程序可以直接调用 SQLite 读写数据，不需要像 MySQL 那样单独部署数据库服务。整个数据库就是一个普通的磁盘文件，备份、复制、移动都很简单。\

  1. 初始化数据库 : 创建 alarm_events 表和相关索引
  1. 插入告警记录
  1. 关闭数据库连接

P3 MQTT(消息队列遥测传输协议)

基于发布/订阅模式的、极其轻量的消息传输协议(特别适合物联网场景)。客户端（传感器、手机App等边缘设备）不直接发送消息给特定接收者，而是发送到代理（Broker，服务器）。接收者向同一个Broker“订阅”自己感兴趣的消息主题。发送者和接收者完全解耦，无需知道对方的存在。

Systemd 服务配置

edgeguard-httpd.service

edgeguard-mqttd.service
