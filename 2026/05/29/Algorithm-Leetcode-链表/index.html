Algorithm-Leetcode-链表

概述(完结)

好久没刷算法题了，新开一个。铁铁我爱刷算法题，至少正反馈强，很多事别说正反馈了连反馈都没有。这是我第二轮刷 Hot 100 了，好多都有点儿遗忘了，有的专题也不熟练，每天刷几道题目倒是不占用太多时间。。。开刷吧，对了我用的是 C++。
第一辑是链表专题，链表专题其实很多套路都差不多感觉，很多都是小模块合并。比如快慢指针找中点，反转链表，dummyNode 哑节点, 这些都是常用的技巧。这边感觉就是纯考验 coding 能力，比如边界条件上的一些处理，基本上就是在不用其他容器的条件下，用有限的几个指针去调整链表。这里面最繁琐的题目可能就是 k 个一组反转链表了吧，label 是 hard，感觉上就是超多超多模块缝合，写起来还是有点难度，但是也不在 hot 100 里面。

206 反转链表
234 回文链表

值得记录

23 合并 K 个升序链表(这题就是小根堆，堆操作每次调整只需要 O(logn) 的时间复杂度，但是 C++ 的语法有点奇怪，不太熟悉模板和比较器的写法)

142 环形链表 II(Floyd 判环算法) 先找相遇点，再找入环节点，如果有入环节点的话必定在循环体中返回改节点。

146 LRU 缓存(双向链表 + 哈希表，实现 O(1) 时间复杂度的查找和插入节点；注意在删除节点的时候也删除哈希表中的键值对，所以既需要 key 也需要 value)

160 相交链表(这题很简单，但老是做错，循环条件写不对)
