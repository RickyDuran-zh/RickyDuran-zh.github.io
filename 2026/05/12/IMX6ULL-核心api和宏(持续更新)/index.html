IMX6ULL-核心api和宏(持续更新)

核心api和宏

注册相关

MODULE_DEVICE_TABLE

声明当前驱动模块所支持的设备列表。当 udev 检测到新设备时，系统会根据该表自动加载对应的驱动模块。

module_i2c_driver()

一个辅助宏，封装了module_init()和module_exit()，简化标准I2C驱动模板的初始化和推出代码。

module_platform_driver()

i2c子系统

i2c_set_clientdata()

将自定义的私有数据结构指针保存到 i2c_client 当中，在驱动的probe函数中常被用来保存设备上下文。

i2c_get_clientdata()

从 i2c_client 中取出之前保存的私有数据结构指针。用于驱动的 read、write 或 remove 回调中。

i2c_smbus_read_i2c_block_data()

从 i2c 设备读取一块连续的数据。它遵循 SMBus 块读取协议。

i2c_smbus_write_byte_data()

向 i2c 设备寄存器的指定地址写入一个字节的数据

i2c_check_functionality()

在发起数据传输前，检查 i2c 适配器（硬件控制器）是否支持需要的传输方式。

gpio子系统

devm_gpid_get()

从设备树或固件中获取指定的 GPIO 引脚，并返回一个 struct gpio_desc 描述符。

gpiod_set_value_cansleep()

misc相关

misc_register()

向系统注册一个杂项设备。Misc 设备通常用于简单的字符设备，它们共享同一个主设备号（10），并自动分配次设备号。

misc_deregister()

注销之前通过 misc_register() 注册的杂项设备，释放设备号。

打印相关

dev_info() / dev_err()

标准的设备驱动日志输出接口。它们会打印带有设备前缀的信息，便于调试和定位问题。

scnprintf()

将格式化字符串输出到指定缓冲区，并保证结果是 NULL 结尾的。用于安全地拼接字符串，避免了 sprintf 可能导致的缓冲区溢出风险。

空间缓冲相关

devm_kzalloc()

为设备分配内存，自动初始化为零，并自动管理内存生命周期。它是内核中推荐的内存分配方式，因为它将内存与 struct device * 绑定。当设备驱动被卸载或设备被移除时，这块内存会自动释放，不需要手动调用 kfree，从而简化了错误处理和移除函数的代码。

simple_read_from_buffer()

在内核驱动的 read 回调函数中，安全地将内核缓冲区数据复制到用户空间。它内部处理了拷贝、偏移量跟踪以及边界检查，是一个非常实用的工具函数，可以避免手动实现这些逻辑

工具类相关

container_of()

通过结构体中某个成员的地址，反推出包含该成员的外层结构体的起始地址。用于将回调参数（通常是某成员指针）转换回该结构体对象。

锁相关

devm_input_allocate_device()

input_set_capability()

input_register_device() && input_unregister_device()

input_event() && input_report_key() && input_sync()
