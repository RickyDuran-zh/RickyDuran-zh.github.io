IMX6ULL-项目开发-Day4

概述

RGB 5寸(分辨率 800 * 480)电容触摸屏，分别打通了显示和触摸的逻辑链路，可以捕获触摸点的坐标位置上报内核，并在 LCD 屏幕上刷新显示。后续考虑加入 qt UI 进行页面的切换。

一、RGB 5寸电容触摸屏

1.硬件相关

2.显示链路

24位数据流，LCD data 引脚和 LCD 相关控制引脚，背光引脚。PWM 子系统 + FrameBuffer(本质就是一块物理内存)。

(a).显示原理

用户往 FrameBuffer(/dev/fb0) 中写数据(mmap), LCD 控制器(eLCDIF)读取数据通过施加电压改变液晶的分子排列从而控制某一颜色的透光亮从而达到显相的目的, PWM 子系统调节背光控制屏幕的亮度。

(b).设备树配置

3.触摸链路

触摸芯片 GT9157, I2C 地址 0x14。I2C 数据和时钟引脚，中断和复位引脚。I2C 子系统计算坐标 + Input 子系统上报坐标事件。

(a).触摸原理

I2C 获取触摸点的坐标信息，通过中断引脚进入中断上下文。在中断上下文中上报坐标事件，用户从/dev/input/event1 中获取具体的坐标信息。

二、mmap，lseek，ioctl(System Call)

mmap

定义: 将进程中的一段虚拟地址空间映射到内存中的一块地址(返回一个内存指针指向一段虚拟的地址空间但映射到了具体内存)。对这个地址空间进行读写操作可以实现直接在用户空间内对内存中的数据进行修改。
什么是页表？ 每一个进程都认为自己独占整个内存，因为进程的地址空间是虚拟的逻辑上的地址范围不同于物理内存。但所谓内存必定是要存储东西的，进程的地址空间存放着诸如代码段，数据段，堆，栈等重要的内容，这个时候就需要CPU 中的 MMU 通过页表来将虚拟的地址空间转换成物理地址。
什么是页缓存？ 页缓存位于内存中的一个缓冲区，暂时存放要从磁盘中读取或写入磁盘的文件数据，以页(4KB)为单位，可以直接理解为内核的缓冲区。
mmap的优势？ 除去磁盘与页缓存中之间的 IO 操作，如果使用诸如 Read、Write 的系统调用，还需要处理两次用户缓冲区和内核页缓存的拷贝操作(因为用户程序不能直接访问内核内存)。mmap 省去了从内核到用户的数据拷贝，节省了用户态缓冲区内存。mmap 还可以实现诸如多个进程 mmap 同一个文件(共享内存)进而实现 高效的IPC；匿名映射，分配大块内存。

lseek

用于移动文件读写位置。移动文件描述符内部的读写位置指针，不读写数据，只告诉内核下一次 read 或 write 从文件的哪个位置开始。

ioctl

用于控制设备执行特定命令。向设备驱动程序发送特定的控制命令，执行那些标准 read/write 无法完成的操作(设置参数，读取状态，执行动作)。

三、/dev 和 /sys 分别作为用户空间与内核空间接口之间的区别

/dev 提供“访问硬件”的通道(数据读写)，/sys 提供“查看和控制硬件”的属性视图(设备配置)
